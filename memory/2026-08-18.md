- 网页版同源 API `/api/list?dir=...`（自动带 cookie）直接返回 JSON，无需滚动 DOM
- 每目录返回 `{dir, subdirs[], file_count, files[前20个]}`（大目录只取前 20 文件名 + 总数，防返回超限）
- evaluate 函数模板：`async () => { const dirs=[...]; for(...) 分页 fetch('/api/list?dir='+encodeURIComponent(d)+'&num=200&order=name&desc=0&showempty=0&web=1&page=1&start='+i); return JSON.stringify(out); }`
