### EC#14 侧边栏重绘丢图标（Row 16）
- **用户情绪**："不能重画，不能重画。画的一模一样也不能重画菜单！！！" -- 极度不满
- **根因**：messages.html 作为独立页面，手写侧边栏时没有加 emoji 图标（总览 vs 📊 总览）
- 切换到留言管理时，导航到新页面，浏览器重新渲染整个 DOM
- 因为侧边栏内容不同（缺图标），用户看到：图标消失、文字位置变化、页面颤动
- **修复**：messages.html 侧边栏加回 emoji 图标（📊 📍 👥 ✦ 💬 ←）
- 部署方式：写服务器 Python 脚本 `/tmp/_cp_msg.py` 用 `shutil.copy()` 避免路径空格问题
- 验证通过：重启 gunicorn 后浏览器检查侧边栏 innerHTML 包含 emoji

### 关键教训：侧边栏内容必须完全一致
- 所有 admin 页面（index/nodes/users/sparks/messages）的侧边栏 HTML 内容必须一字不差
- 任何差异（缺图标、不同缩进、不同样式）都会在导航时被用户发现
- 当前架构是传统多页应用，切换页面必然 DOM 重绘。但是界面必须看起来完全一致
- 理想方案：Jinja2 base template 统一管理侧边栏。但需要重构所有 admin 模板

```
echo 'import shutil; shutil.copy("SOURCE", "DEST")' | ssh ... python3
```
