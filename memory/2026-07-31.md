## dev 站 502 故障排查与修复

问题：dev.zhichangxuan.com 报 502，生产站正常。

根因追溯：
- 2026-07-30 20:12:00 — 最后一次成功访问 dev（API 200）
- 2026-07-30 20:54:52 — 跑 deploy.sh 部署生产，`pkill -f "gunicorn.*longmarch"` 无差别杀了 dev 的 gunicorn
- 2026-07-30 21:08:34 — dev 第一次 502（之后一直死着）
- 2026-07-31 08:28 — 用户发现 dev 挂

修复：
1. 重启 dev gunicorn
2. 装 systemd 服务 `longmarch-dev.service`，`Restart=always`
3. 生产也装 systemd 服务 `longmarch-map.service`（之前是裸 --daemon 启动）
4. 修改 `deploy.sh`：
   - 移除 `pkill -f "gunicorn.*longmarch"`（这是杀 dev 的元凶）
   - 改用 `systemctl stop/restart ${APP_NAME}`，只操作生产
   - 状态检查改为 systemctl is-active
