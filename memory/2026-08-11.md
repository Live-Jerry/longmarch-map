## GitHub 推送问题：根因 + 中转方案（彻底解决）

### 最终根因（2026-08-11 深度诊断，修正了上午的误判）
- 不是“网络不通/GFW 重置”，而是：**运营商/中间设备对 GitHub 亚洲段 IP 的间歇性 QoS 限速**
- 证据：curl 连接 github.com 成功但吞吐被限到 ~35KB/s（432KB 收不完就超时）；TCP 握手基本都通（Test-NetConnection 5/5）；时好时坏（10 次 TLS 测试 2-8 次失败）
- 本地 DNS 解析 github.com → 20.205.243.166（亚洲段，被限速）；换 20.200.245.247（亚洲段）也不稳（2/5）
- 美国段 140.82.112.3 / 140.82.114.3：curl 4/4 + git 5/5 全部稳定；185.199.x（Fastly）不行（0/4）
- SSH 协议走 ssh.github.com:443：5/5 稳定（SSH 流量特征不同，未被限速）

### 最终解决方案（已生效，本地直连）
- `git config --global "http.https://github.com/.curloptResolve" "github.com:443:140.82.112.4"`
- 原理：git 层强制 github.com 走美国段稳定 IP，无需管理员改 hosts
- **重要教训：QoS 是按 IP 间歇限速的，单 IP 会随时失效（140.82.112.3 曾 4/4+5/5 稳定，12:41 就 000 失败）**；失效时扫描候选 IP 换新的
- 候选 IP 清单（2026-08-11 扫描）：140.82.112.4（当前在用，5/5）、140.82.116.3、140.82.114.3、140.82.112.3、20.205.243.166（亚洲段，时好时坏）；20.200.245.247 与 185.199.x 不可用（000）
- 切换命令：git config --global "http.https://github.com/.curloptResolve" "github.com:443:<新IP>"
- 长期最稳：SSH 通道（ssh.github.com:443 多次 5/5 稳定，SSH 流量未被限速），key 加到 GitHub 后 remote 切换为 ssh://git@ssh.github.com:443/Live-Jerry/longmarch-map.git
- 辅助配置：http.version=HTTP/1.1、http.lowspeedlimit/time=1000/30、postBuffer=512MB
- 用户还在 hosts 加过 `20.200.245.247 github.com`（亚洲段，会被限速）——建议改为 140.82.112.3 或删除（git 不受影响，但浏览器等走 hosts）

### 中转方案（保留为兑底，不再必须）
- 脚本：`007 项目工具/push_via_server.ps1`（UTF-8 BOM，PowerShell 5.1 兼容）
- 基准：`.git/zcx_last_pushed`；服务器中转仓库 /root/zcx-git；服务器凭据 /root/.git-credentials
- 用途：本地直连再次失效时运行；网络正常时直接 git push origin develop

### 历史统一（中转 am 与本地 SHA 分叉处理）
- 现象：push 报 rejected (fetch first)——远程 938a455（am 产物）vs 本地 c27d80d（同内容不同 SHA）
- 处理：fetch origin → reset --soft origin/develop（保留工作区）→ 重新 commit（a54c5e8）→ push 成功
- 经验：中转推送后本地需 soft reset 对齐，避免 SHA 分叉累积

### 根因（诊断结果）
- 本地 TCP 443 能连 github.com（TcpTestSucceeded=True），但 TLS/HTTP 层被重置（curl direct: 000 超时）——典型的网络干扰
- 系统代理配置了 http://127.0.0.1:10808（v2rayN 类）但 ProxyEnable=0 且 10808 无进程监听 → 代理软件未运行，git 也无代理配置
- 服务器访问 GitHub 完全正常（200，0.7s），git ls-remote/push 认证有效
- 之前 memory 说“服务器 push 可能报 Invalid username or token”只是猜测，实际验证服务器认证有效（已配置 /root/.git-credentials）
