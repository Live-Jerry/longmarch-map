# 知常轩公益网站建站方案

版本：V1.0    日期：2026-08-07    状态：草案待评审
定位：面向中小学生和家长的传统文化与科学知识公益网站

---

## 一、品牌与理念

### 1.1 名称释义

「知常」出自《道德经》第十六章：归根曰静，静曰复命，复命曰常，知常曰明。不知常，妄作凶。知常容，容乃公，公乃全，全乃天，天乃道，道乃久，没身不殆。

- 知常：知晓恒常不变的道理，即事物的底层逻辑与客观规律
- 轩：古建筑中的廊轩、书斋，引申为处所、学舍

知常轩 = 一个学习底层逻辑、客观规律、科学知识的群体、组织与处所。

### 1.2 使命与定位

- 使命：传播中华优秀传统文化、现代科学知识，帮助青少年建立正确的世界观、人生观、价值观
- 定位：纯公益、无广告、无商业变现的知识网站
- 服务对象：中小学生（核心）与家长（陪伴与引导）
- 差异化：不讲空洞口号，讲道理、讲逻辑、讲证据；传统文化与现代科学并重，贯通古今

### 1.3 核心理念（内容红线）

1. 实事求是——每个知识点可查证、有出处
2. 科学精神——鼓励提问、质疑、验证
3. 文化自信——以理服人，不煽情、不盲从
4. 面向成长——内容分级、适龄呈现、家长参与

### 1.4 口号候选

- 知常曰明，明理致远
- 知常轩：知常理，明大道，育少年
- 学传统之智慧，知科学之规律

## 三、模块详细规划

### 模块一：中国哲学

定位：哲学启蒙——用孩子听得懂的话讲"为什么"

栏目与内容：
1. 哲学启蒙问答——什么是哲学、什么是道理、什么是逻辑（每篇 500-800 字 + 配图）
2. 诸子百家——孔子、老子、庄子、孟子、荀子、墨子、韩非子、孙子（人物志：生平、主张、名言、故事）
3. 寓言与思辨——庄周梦蝶、庖丁解牛、塞翁失马、白马非马、刻舟求剑（每篇含「想一想」提问）
4. 名言新解——每日一句：原文、注音、今译、生活场景举例
5. 思维方法入门——归纳与演绎、类比、因果、换位思考（结合小实验/小案例）

首批内容清单（示例 12 篇）：
- 什么是哲学？哲学是"爱智慧"
- 老子：道是什么？道法自然
- 庄子的三条鱼：鲲鹏、涸辙、濠梁
- 塞翁失马：坏事一定会变好事吗
- 白马非马：一个古人的逻辑游戏
- 刻舟求剑：为什么求不到剑
- 孟子的"四端"：人为什么有恻隐之心
- 墨子的兼爱：爱别人就是爱自己吗
- 韩非子的矛盾：自相矛盾的由来
- 孙子的知己知彼：打游戏也用得上的道理
- 归纳与演绎：从乌鸦到"天下乌鸦一般黑"
- 想一想专栏：如果世界没有规律

### 模块二：经典古籍

定位：读原典、知出处——给孩子的古籍入门

栏目与内容：
1. 蒙学经典——三字经、百家姓、千字文、弟子规、声律启蒙、笠翁对韵（注音 + 白话 + 朗读音频）
2. 四书五经导读——论语、大学、中庸、孟子、诗经、尚书、礼记、周易、春秋（选篇精读）
3. 史部名著——史记选读（本纪、列传故事化）、资治通鉴选读
4. 经典名句库——按主题分类（立志、勤学、修身、交友、家国），可检索
5. 古籍今译对照——原文/逐句注释/白话翻译三段式排版
6. 亲子共读计划——每季一份"共读 20 篇"书单与进度打卡

首批内容清单（示例 12 篇）：
- 三字经全文注音朗读（分段 10 讲）
- 千字文：天地玄黄，宇宙洪荒
- 论语·学而篇精读：学而时习之
- 论语·为政篇：为政以德，譬如北辰
- 大学·三纲领八条目：修身齐家治国平天下
- 中庸：中也者，天下之大本也
- 诗经·关雎：风雅颂是怎么来的
- 史记·孔子世家：孔子一生走了哪些路
- 史记·项羽本纪：破釜沉舟的故事
- 资治通鉴·三家分晋：历史的起点
- 周易入门：太极、两仪、四象、八卦是什么
- 亲子共读计划·第一期：蒙学 20 篇

### 模块三：儒与道

定位：两大思想源流的对照与运用

栏目与内容：
1. 儒家之道——仁、义、礼、智、信（逐字拆解 + 现代场景）
2. 道家之道——道法自然、无为、上善若水、柔弱胜刚强
3. 儒道对照——出世与入世、进取与顺势（对比表 + 讨论题）
4. 人物故事——孔子周游列国、老子出函谷、庄子拒聘、孟子见梁惠王
5. 生活应用——怎样交朋友（信）、怎样面对失败（水）、怎样管理情绪（礼）
6. 家长课堂——如何跟孩子讲儒道（写给家长的导读）

首批内容清单（示例 10 篇）：

- 上善若水：水有七善
- 无为：不妄为，不是不做事
- 孔子 vs 老子：如果两位老师相遇
- 家长课堂：孩子问"为什么要善良"怎么答

| 冰裂纹 | 页面背景暗纹（低透明度水印） |
| 水波纹 | 页脚顶部分隔 |
| 方胜纹 | 栏目标签图标 |
| 如意纹 | 「每日一句」等专题卡片装饰 |

实现方式：SVG 内联或独立 .svg 文件，CSS background / mask 引用；背景纹样统一低透明度（约 4%-8%），保证文字可读性。

### 5.3 字体与版式

- 标题字体：思源宋体（免费可商用）为主，重要标题可衬楷体（如 霞鹜文楷）
- 正文字体：系统宋体/黑体栈（Windows: 宋体、微软雅黑；移动端系统默认）
- 古籍内容：楷体呈现原文 + 宋体注释
- 版式特征：模块标题采用「竖排小字引题 + 横排大字主题」组合；卡片圆角克制（4-8px），描边用金/黛灰细线；印章式 Logo 元素点缀（朱砂色"知常轩"方印）
- 响应式：移动端单列、模块网格 2 列；桌面 3-4 列

### 5.4 组件风格约定

- 按钮：朱砂底、牙白字，hover 转绛红，四角回纹微装饰
- 标签：藤黄底墨字 / 竹青底白字（模块色彩标识）
- 卡片：牙白底、1px 黛灰描边、顶部 3px 朱砂/模块色条
- 文章页：宣纸底、正文段首缩进、引用块用竹青左边线
- 页脚：黛蓝底、牙白字、水波纹分隔 + 备案信息（ICP + 公安备案，沿用现有 #icp-footer）

## 七、内容生产与合规（面向未成年人，重点章节）

### 7.1 内容来源与版权

- 古籍原文、历史事实：公有领域，放心使用，标注出处（如《论语》《史记》）
- 白话解读、故事改编：自撰原创，标注作者
- 图片：优先自绘/原创 SVG 与插画；历史照片标注来源与授权状态；碑帖图用公有领域高清资源
- 音频：TTS 合成 + 后期志愿者配音并行
- 转载原则：一律不转载未授权内容；引用注明出处

### 7.2 未成年人保护合规（《未成年人保护法》网络保护专章）

1. 不收集儿童个人信息：浏览无需注册；投稿/留言仅需昵称（可匿名），不要求年龄、学校、手机号
2. 家长模式：家长注册后可设置「共读模式」（查看孩子学习记录——仅本站内行为数据，不外传）
3. 内容适龄分级：每篇标注适龄建议（6-9 / 10-12 / 13-15），恐怖、战争等内容弱化血腥描写
4. 审核机制：投稿与留言先审后发（沿用现有 spark 审核流程）
5. 举报通道：页面提供举报入口，处理时限承诺
6. 防沉迷：无自动播放流、无信息流无限刷；鼓励定时学习（每日一句 + 单篇阅读）
7. 无广告、无付费、无外链商业推广

### 7.3 价值观审核要点

- 历史内容：以真实史料为基础，避免戏说与过度演绎
- 哲学宗教内容：讲思想、讲逻辑，不搞迷信、不传教
- 科学内容：可证伪、可查证，错误及时更正并公示

### 7.4 内容生产节奏（上线后）

- 每日：每日一句 + 一首诗（诗歌模块）
- 每周：每模块 1-2 篇新文章（约 10 篇/周）
- 每月：1 个专题（如"长征月""科学月"）
- 每季：家长共读计划更新
