# 知常轩 网站建站方案

> 名称出处：《道德经》"知常曰明"——知晓恒常之理，方为真正的明智
> 轩：古建筑之名，亦为处所。知常轩，即"探求恒常之理的所在"

---

## 一、项目概述

### 1.1 网站定位

| 项目 | 说明 |
|------|------|
| **名称** | 知常轩 |
| **性质** | 公益文化传播平台 |
| **使命** | 传播传统文化、科学知识、正确的世界观人生观价值观 |
| **受众** | 初中生、高中生、小学高年级学生及学生家长 |
| **核心价值** | 底层逻辑 · 客观规律 · 科学精神 · 文化自信 |

### 1.2 设计总纲

- **色彩体系**：中国传统五色（青、赤、黄、白、黑）为主调，辅以现代中性色
- **装饰语言**：中国传统纹样（云纹、回纹、祥云、龙凤、梅兰竹菊）
- **字体排版**：正文宋体/楷体，标题篆隶风格，兼顾现代可读性
- **整体调性**：典雅而不古板，厚重而有活力，适合青少年与家长共同阅读

### 模块一：中国哲学

**模块定位**："哲学是全部科学之母"——帮助青少年建立思维框架，理解世界本质

#### 色彩主调：玄青 + 缃黄

#### 内容结构

**1. 先秦诸子（入门篇）**

| 栏目 | 内容 | 形式 |
|------|------|------|
| 诸子群像 | 儒道法墨名阴阳，介绍12位先秦思想家生平与核心主张 | 图文 + 趣味问答 |
| 思想地图 | 诸子百家的师承关系、争论焦点可视化图 | 交互图表 |
| 漫画诸子 | 每位思想家3~5幅漫画故事 | 漫画连载 |

**2. 中国哲学核心概念（词典式）**

| 概念 | 哲学含义 | 生活联系 |
|------|----------|----------|

| 天人合一 | 人与自然和谐 | 生态文明 |
| 中庸 | 恰到好处之德 | 为人处世 |

**3. 思维方法专题**

```
- 如何用"矛盾分析法"看待新闻事件？
- "知行合一"与学习习惯养成
- 从"盲人摸象"中学全面看问题
- 概率思维：庄子"以有涯随无涯"与现代学习
```

**4. 青少年哲学对话**

```
- "我是谁"——从笛卡尔到王阳明

### 模块三：儒与道

**模块定位**：理解儒家积极入世与道家超然物外两种人生智慧——儒道互补，才是完整的中国精神

#### 色彩主调：缃黄 + 翠青

#### 内容结构

**1. 儒家思想体系**

```
① 儒学发展脉络
   孔子 → 孟子 → 荀子 → 董仲舒 → 朱熹 → 王阳明

② 儒家核心价值观
   仁：仁者爱人——如何培养同理心
   义：正当正义——面对选择时的取舍
   礼：社会规范——礼仪之邦的现代意义
   智：明辨是非——批判性思维
   信：诚实守信——立身之本

③ 《论语》名句精讲（50句）
   每句：原文 + 今译 + 现实应用 + 讨论问题
   例："己所不欲，勿施于人"→ 换位思考与社交礼仪

④ 儒家与现代教育
   - 因材施教的教育理念
   - 学而时习之与高效学习
   - 有教无类与教育公平
```

**2. 道家思想体系**

```
① 道家发展脉络
   老子 → 庄子 → 黄老道家 → 魏晋玄学

② 道德经精讲（81章，逐章解读）
   例：第1章"道可道，非常道"——语言与真理的局限
   例：第16章"致虚极，守静笃"——专注与内心平静
   例：第47章"不出户，知天下"——经验与认知的关系

③ 庄子的故事与哲理
   - 庄周梦蝶：真实与虚幻
   - 庖丁解牛：技艺与道
   - 井蛙不可以语海：认知边界
   - 材与不材：处世智慧

④ 道家与现代生活
   - 无为而治：不是躺平，是顺势而为
   - 上善若水：柔弱胜刚强的人生策略
   - 道法自然：尊重客观规律
```

**3. 儒道对比专题**

| 主题 | 儒家态度 | 道家态度 |
|------|----------|----------|
| 人生价值 | 积极入世，建功立业 | 超然物外，精神自由 |
| 面对困境 | 刚健自强 | 顺势而为 |
| 人际关系 | 仁爱推恩 | 自然疏放 |
| 学习态度 | 勤学不倦 | 得意忘言 |
| 教育方式 | 有教无类 | 不言之教 |

### 模块四：书法文化

**模块定位**：书法是中华文化的基因工程——让孩子不仅会写字，更能欣赏书法之美

#### 色彩主调：墨黑 + 月白 + 青瓷

#### 内容结构

**1. 书法简史（时间线互动）**

```
甲骨文 → 金文 → 大篆 → 小篆 → 隶书 → 楷书 → 行书 → 草书
（配各书体代表作品图片与简要说明）
```

**2. 五体书详解**

| 书体 | 代表人物 | 风格特点 | 代表作 | 适合入门 |
|------|----------|----------|--------|----------|
| 篆书 | 李斯 | 圆转均匀，庄严古朴 | 峄山碑 | 否 |
| 隶书 | 蔡邕/钟繇 | 横挑波磔，左右舒展 | 乙瑛碑/张迁碑 | 是（首选入门） |
| 楷书 | 颜柳欧赵 | 端正规范，法度严谨 | 玄秘塔/九成宫 | 是（最佳入门） |
| 行书 | 王羲之/颜真卿 | 流畅灵动，介于楷草 | 兰亭序/祭侄文稿 | 是（楷书之后） |
| 草书 | 张旭/怀素 | 狂放不羁，气韵生动 | 古诗四帖/自叙帖 | 否（后期） |

**3. 名家名帖赏析**

```
- 王羲之《兰亭序》：天下第一行书
- 颜真卿《祭侄文稿》：满腔悲愤落笔成书
- 苏轼《黄州寒食帖》：诗意书法双重绝唱
- 黄庭坚《松风阁诗帖》：长枪大戟的开创者
- 赵孟頫《洛神赋》：美字配美文
```

**4. 书法入门教程**

```
阶段一：认识工具
  毛笔分类（狼毫/羊毫/兼毫）+ 选笔建议
  墨汁推荐（常见品牌对比）
  宣纸选择（生宣/熟宣/半生熟）

阶段二：笔画基础（楷书入门）
  横竖撇捺点折钩提 8种基本笔画
  每种笔画：起笔、行笔、收笔讲解
  配视频演示

阶段三：结构原则
  重心平稳
  疏密得当
  收放有致
  参差错落

阶段四：碑帖来临摹
  推荐入门碑帖及临写要点
```

**5. 趣味书法**

```
- 汉字演变动画（甲骨文→现代汉字）
- 书法家故事（漫画形式）
- 错别字识别（书法中的异体字）
- 匾额文化：那些挂在殿堂上的书法
```

### 模块五：诗歌国度

**模块定位**：诗不是用来背的，是用来感受的——让孩子真正体会诗词之美，而不只是应付考试

#### 色彩主调：翠青 + 霜白

#### 内容结构

**1. 诗词发展史**

```
诗经 → 楚辞 → 汉赋 → 乐府 → 唐诗 → 宋词 → 元曲 → 近现代诗
（时间轴 + 代表人物 + 风格特点）
```

**2. 诗词分类阅读**

**A. 山水田园诗派**
```
代表：王维、孟浩然、陶渊明
主题：寄情山水、归隐田园
经典篇目：
  - 王维《山居秋暝》：诗中有画
  - 陶渊明《饮酒·其五》：采菊东篱
  - 孟浩然《过故人庄》：田园生活之美
核心方法：意象分析法（松、竹、菊、鸟、山、水的象征含义）
```

**B. 边塞军旅诗派**
```
代表：高适、岑参、王昌龄
主题：边塞风光、报国壮志
经典篇目：
  - 岑参《白雪歌送武判官归京》：奇寒壮别
  - 王昌龄《出塞》：但使龙城飞将在
  - 高适《别董大》：莫愁前路无知己
关联学习：地图上的边塞诗（结合地理知识）
```

**C. 咏史怀古诗**
```
代表：杜甫、刘禹锡、苏轼
主题：以史为鉴，感慨兴衰
经典篇目：
  - 杜甫《蜀相》：出师未捷身先死
  - 刘禹锡《乌衣巷》：旧时王谢堂前燕
  - 苏轼《念奴娇·赤壁怀古》：大江东去
方法：知人论世（了解诗人背景才能读懂诗意）
```

**D. 送别诗与友情**
```
经典篇目：
  - 王勃《送杜少府之任蜀州》：海内存知己
  - 李白《黄鹤楼送孟浩然之广陵》：孤帆远影
  - 王维《渭城曲》：劝君更尽一杯酒
延展：现代人的送别——如何优雅地告别
```

**3. 诗词创作入门**

```
- 押韵规则（平仄入门）
- 常见意象词典（100个核心意象）
- 绝句写作四步法
- 对联基础与趣味对联
- 仿写练习：从五言绝句开始
```

**4. 诗词与科学**

```
创新栏目！用科学解释诗词中的自然现象：
- "月落乌啼霜满天"——月亮升起落下的时间规律
- "春风不度玉门关"——季风与地理
- "夜来风雨声"——天气系统
- "遥知不是雪"——视觉与错觉
- "春江水暖鸭先知"——比热容与季节变化
```

**5. 诗词闯关（互动游戏）**

```
- 诗句接龙
- 看图猜诗
- 飞花令（按主题分类）
- 诗人身份测试
```

### 模块七：长征精神

**模块定位**：长征是宣言书、长征是宣传队、长征是播种机——理解长征，才能理解中国共产党为什么能

#### 色彩主调：缃黄 + 绛赤

#### 内容结构

**1. 长征全景（地图交互）**

```
起点：江西瑞金
终点：陕西吴起镇 / 甘肃会宁
总行程：约25,000里
时间：1934年10月—1936年10月
主要路线：湘江→乌江→遵义→赤水→金沙江→大渡河→雪山→草地→腊子口→会宁
参与部队：红一方面军、红二方面军、红四方面军、红二十五军
```

**2. 长征重要节点**

**节点一：湘江战役**
```
背景：红军第五次反围剿失败，被迫战略转移
惨烈：8.6万人锐减至3万人
意义：血战湘江，为遵义会议创造条件
精神：勇于突破、敢于牺牲
