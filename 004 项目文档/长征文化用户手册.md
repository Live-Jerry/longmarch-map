# 长征文化数字地图 — 用户手册

版本: V005 · 2026-07-16

## 一、产品理念与目的

### 1.1 为什么做这个产品

长征是中国共产党和红军在 1934-1936 年间进行的一次战略大转移，途经 14 个省，行程约二万五千里。长征不仅是一次军事行动，更是一种精神象征。

长征文化数字地图 是一个交互式卫星地图平台，旨在：
- 用现代数字技术还原长征的完整路线和关键节点
- 以多媒体形式（图片、文字、语音）呈现每个节点的历史细节
- 让用户在"重走长征路"的过程中身临其境感受那段历史
- 吸引公众参与历史资料的收集与分享（星火拾遗）

### 1.2 核心设计理念

- 交互性：用户通过点击地图上的红旗标记探索节点，支持自动漫游
- 开放性：任何用户无需注册即可提交史料（星火拾遗），经审核后入库
- 多媒体：每个节点包含战役、会议、事件、遗址、人物、诗词等多维度信息
- 参与感：留言板、星火投稿等机制让用户从"看客"变为"参与者"

### 1.3 适用对象

- 历史爱好者、红色文化研究者
- 中小学师生（作为爱国主义教育辅助工具）
- 党员教育、红色旅游导览
- 对长征感兴趣的普通公众

## 二、功能介绍

### 2.1 交互式卫星地图

- 底图切换：支持 ArcGIS 卫星图（默认）和 OpenStreetMap 浅色/深色地图
- 节点标记：所有长征节点以红旗标记标注在地图上
- 点击交互：点击红旗下方的编号标签，弹出信息面板
- 军队路线：支持显示中央红军、红二方面军、红四方面军、红 25 军四支军队的行军路线

### 2.2 节点信息面板

每个节点打开后显示 5 步信息：

| 步骤 | 内容 |
|------|------|
| ① 时间与地点 | 事件发生的时间、地点、编号 |
| ② 著名战役 | 战役名称、经过、结果（如适用） |
| ③ 重要会议 | 会议名称、时间、决议（如适用） |
| ④ 历史事件 | 核心事件描述 |
| ⑤ 历史意义 | 事件的历史地位与影响 |

此外还包含：
- 核心数字（歼敌数、行军人数、温度等）
- 典型故事与典型人物
- 诗词文章（如《七律·长征》等）
- 核心遗址（纪念馆、纪念碑、旧址等）
- 节点图片（自动加载相关历史照片）

### 2.3 自动漫游

- 沿长征路线自动移动，模拟 30km/h 速度
- 到达每个节点自动弹出信息面板
- 支持语音朗读（TTS，中文语音合成）
- 控制功能：暂停/继续、跳过当前节点、重头开始、退出漫游
- 速度选择：慢速（3s/节点）、中速（2s/节点）、快速（1s/节点）

### 2.4 星火拾遗（用户贡献）

- 无需注册即可提交长征相关素材
- 支持两种模式：
  - 新建节点：自行定义新节点（编号、标题、经纬度、内容等）
  - 补充既有节点：为现有节点增加内容
- 支持文件上传：图片、视频、音频、文档
- 提交者信息可选（姓名、电话）
- 所有内容进入待审核状态，由管理员审核后发布

### 2.5 用户认证

- 注册：创建账号（用户名 ≥ 3 字符，密码 ≥ 6 字符）
- 登录：使用用户名和密码登录
- 忘记密码：重置密码（验证用户名后设置新密码）
- 登录后星火投稿可追踪个人提交记录

### 2.6 留言板

- 查看所有用户留言
- 登录后可发表留言
- 留言与长征节点关联

### 2.7 管理后台

- 管理员入口（需 admin/super 角色）
- 用户管理：查看、角色修改、删除
- 节点管理：CRUD 操作
- 星火审核：通过/拒绝用户提交的内容

## 三、操作说明

### 3.1 快速开始

1. 在浏览器中打开应用（查看部署后的实际地址）
2. 页面加载后，自动显示长征路线和节点标记
3. 点击地图上任意红旗节点的编号标签（如 13.1），右侧弹出信息面板
4. 点击面板下方的 朗读 按钮收听语音讲解

### 3.2 控制栏说明

右侧纵向控制栏包含以下按钮（从上到下）：

| 名称 | 功能 |
|------|------|
| 语音 | 打开/关闭语音播报 |
| 漫游 | 打开自动漫游面板，设置速度并开始漫游 |
| 军队 | 选择军队路线（中央红军/红二方面军/红四方面军/红25军） |
| 星火 | 打开星火拾遗投稿弹窗 |
| 卫星 | 切换卫星图/普通地图/深色地图 |
| 留言 | 打开/关闭留言板 |
| 登录 | 打开认证弹窗（登录/注册/忘记密码） |
| 帮助 | 打开本用户手册 |
| 管理 | 进入管理后台（仅管理员显示） |

### 3.3 探索节点

方法一：直接点击
1. 在地图上找到有红色军队标记的节点
2. 鼠标悬停时标记会放大，显示节点编号
3. 点击编号标签（红色文字），左侧弹出信息面板

方法二：自动漫游
1. 点击控制栏的 漫游 按钮
2. 在弹出的面板中选择速度（慢速/中速/快速）
3. 点击 开始 按钮
4. 地图会自动沿路线移动到每个节点并弹出信息
5. 使用顶部状态栏的暂停/跳过/重头/退出控制漫游

### 3.4 切换军队路线

1. 点击控制栏的 军队 按钮
2. 在下拉菜单中选择：
   - 中央红军（红一方面军）— 红色
   - 红二方面军 — 绿色
   - 红四方面军 — 蓝色
   - 红 25 军 — （另行标注）
3. 地图自动切换对应的行军路线

### 3.5 提交星火内容（无需注册）

1. 点击控制栏的  星火 按钮
2. 选择模式：
   - 新建节点：填写节点编号、标题、地区、时间、经纬度（点击地图拾取）
   - 补充既有节点：从下拉列表选择要补充的节点
3. 填写历史内容字段（战役、会议、事件、故事等）
4. 可选上传多媒体文件（图片、视频、音频、文档）
5. 可选填写提交者姓名和电话
6. 点击 提交审核 按钮
7. 内容进入待审核状态，经管理员审核后发布

### 3.6 登录/注册

1. 点击控制栏的  登录 按钮
2. 弹窗中三个标签页：
   - 登录：输入用户名和密码
   - 注册：创建新账号（两遍密码确认）
   - 忘记密码：输入用户名和新密码重置
3. 登录成功后按钮变为  退出
4. 单击退出按钮即可登出

### 3.7 留言

1. 点击控制栏的  留言 按钮
2. 在留言板输入框中输入内容
3. 点击发送（登录后方可发送）
4. 所有留言按时间倒序显示

### 3.8 管理后台

> 需要 admin 或 super 角色权限

1. 登录管理员账号后，控制栏自动显示  管理 按钮
2. 点击进入管理后台
3. 左侧导航栏：
   - 仪表盘 — 系统统计数据
   - 节点管理 — 增删改查长征节点
   - 用户管理 — 查看和管理用户
   - 星火审核 — 审核/拒绝用户提交的内容

## 四、常见问题

### Q: 星火投稿需要注册吗？
不需要。任何用户都可以直接提交星火内容，提交者信息（姓名/电话）可选填写。

### Q: 提交星火后多久能显示？
管理员审核通过后即显示。审核时间取决于管理员的处理。

### Q: 忘记密码怎么办？
在认证弹窗中点击"忘记密码"标签页，输入用户名和新密码即可重置。

### Q: 如何成为管理员？
目前管理员账号由系统初始化时创建（默认账号见部署配置），普通用户无法自行升级。

### Q: 可以上传哪些类型的文件？
图片（jpg/png/gif/webp）、视频（mp4/avi/mov）、音频（mp3/wav/ogg）、文档（pdf/doc/docx/txt）。

### Q: 自动漫游时如何手动查看某个节点？
点击暂停按钮暂停漫游，然后直接在地图上点击你想看的节点标记。漫游会继续播放剩余路线。
