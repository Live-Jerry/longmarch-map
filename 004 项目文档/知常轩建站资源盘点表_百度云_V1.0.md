## 二、核心资源与知常轩模块映射（A/B/C 三级）

### 分级定义
- A 级：公有领域/古籍原文，可直接加工为网站内容（提取、校对、排版、配音）
- B 级：可作加工底本/参考，需核实版权或仅取其中公有领域部分
- C 级：现代出版物/课程视频，仅做「延伸阅读」书目导航，不上传内容

## 四、与知常轩建站的结合路径

1. 首批选品（A 级优先，建议 3-5 篇样章）：
   - 儒与道模块：《道德经》选章（道法自然/上善若水）+《论语》选章（学而/为政）
   - 经典古籍模块：《增广贤文》选段 + 《史记》名篇（项羽本纪破釜沉舟）
   - 诗歌国度模块：小学生必背古诗 10 首精讲（原文公有领域，讲稿自撰）
2. 加工流水线：网盘下载 → Python 提取文本（PyMuPDF）→ 人工校对 → 三段式排版（原文/注释/译文）→ 注音 → TTS 朗读 → 审核 → 入库发布
3. 书目导航栏目：C 级资源统一进「延伸阅读」库（书名/作者/出版社/导读），随模块上线同步填充
4. 后续扩展：书法图库（碑帖 A 级）可做「碑帖欣赏」专栏，与书法文化模块联动
