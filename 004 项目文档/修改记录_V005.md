## 1. 星火拾遗 — 去掉登录要求

### 背景
用户提交星火内容（民间史料、照片、录音等）时，原先要求用户必须登录。根据产品决策，改为无需登录即可提交。

### 改动文件

| 文件 | 修改 |
|------|------|
| `api/spark_api.py` | `submit_spark()` 去掉 `AuthManager.current_user()` 的 None 检查；`create_full_spark()` 去掉 `require_login()`，改为可选获取用户 |
| `static/js/spark.js` | 提交 `/full` 时，有 token 才发 Authorization 头，无 token 时省略 |
| `interfaces/spark_interface.py` | 更新接口文档，标注"公开（无需登录）"，补充 `/full` 端点文档 |

### 关键逻辑
- 登录用户提交：`user_id` 存用户 ID
- 匿名用户提交：`user_id` 存 `NULL`
- 提交者信息（姓名/电话）通过表单字段 `submitter_name` / `submitter_phone` 收集，存入 `content` JSON
- 无论是否登录，所有提交均进入 `pending` 状态，需管理员审核
- 数据库 `spark` 表的 `user_id` 列已是 nullable，无需迁移

## 2. 认证系统 — 弹窗集成注册/忘记密码

### 背景
原来登录按钮跳转独立 `/login` 页面，注册有独立 `/register` 页面。改为在主页右侧控制栏点击登录按钮时，打开弹窗（modal），弹窗内集成三个标签页：登录、注册、忘记密码。

### 改动文件

| 文件 | 修改 |
|------|------|
| `api/auth_api.py` | 新增 `POST /api/v1/auth/reset-password` 端点 |
| `services/auth_manager.py` | 新增 `reset_password()` 方法 |
| `models/user.py` | 新增 `update_password()` 类方法 |
| `static/js/auth.js` | 新增弹窗控制函数、三个表单处理器、`resetPassword()` API 函数；改造 `updateAuthUI()` |
| `templates/index.html` | 新增认证弹窗 HTML（登录/注册/忘记密码三个表单页面，底部链接导航切换） |
| `static/css/style.css` | 新增 `.auth-form-panel` 样式 |

### 新 API

```
POST /api/v1/auth/reset-password
请求: { "username": "...", "new_password": "..." }
响应: { "code": 0, "message": "密码重置成功，请使用新密码登录" }
```

### 用户流程
1. 点击右侧「 登录」→ 打开认证弹窗
2. 弹窗三个标签页：登录 / 注册 / 忘记密码
3. 注册成功自动登录并关闭弹窗
4. 忘记密码重置成功后自动切回登录页
5. 登录后按钮变为「 退出」，单击退出

### 兼容性
- 独立 `/login` 和 `/register` 页面仍然保留，可直接访问
- 独立页面与弹窗共用 `auth.js` 中的 `login()` / `register()` / `resetPassword()` 函数

### 设计变更
- 去掉顶部三个标签页按钮（登录/注册/忘记密码），改为底部文字链接切换
- 用户流程：登录页底部「立即注册」「忘记密码？」→ 注册页底部「立即登录」→ 重置页底部「← 返回登录」
- 更符合常见弹窗设计惯例
