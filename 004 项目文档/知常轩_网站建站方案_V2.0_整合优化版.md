# 知常轩 网站建站方案 V2.0（整合优化版）

> 本版整合《知常轩_网站建站方案.md》（原稿）与《知常轩公益网站建站方案_V1.0.md》，并新增「资源访问架构」章节。

## 一、项目概述

### 1.1 网站定位

| 项目 | 说明 |
|------|------|
| **名称** | 知常轩 |
| **性质** | 公益文化传播平台（无广告、无付费） |
| **使命** | 传播传统文化、科学知识，帮助青少年建立正确的世界观、人生观、价值观 |
| **受众** | 小学生高年级、初中生、高中生及学生家长 |
| **核心价值** | 底层逻辑 · 客观规律 · 科学精神 · 文化自信 |
| **差异化** | 不讲空洞口号，讲道理、讲逻辑、讲证据；传统文化与现代科学并重，贯通古今 |

### 1.2 设计总纲

- **色彩体系**：中国传统五色（青、赤、黄、白、黑）为主调，辅以现代中性色
- **装饰语言**：中国传统纹样（云纹、回纹、祥云、缠枝、冰裂、梅兰竹菊）
- **字体排版**：正文宋体/楷体，标题篆隶风格，兼顾现代可读性
- **整体调性**：典雅而不古板，厚重而有活力，适合青少年与家长共同阅读

## 二、视觉识别系统（VI）

### 2.1 中国传统色彩体系（统一色板）

| 色名 | 色值 | 用途 |
|------|------|------|
| **玄青**（玄色） | `#1C1C2E` / `#0D0D1A` | 主背景（深色区块）、页脚背景 |
| **缃黄** | `#E8C547` | 强调色、高亮文字、标签 |
| **绛赤** | `#C73E3A` | 重要提示、印章、主按钮、长征模块标识 |
| **翠青** | `#2D6A4F` | 科学模块主色、正确反馈 |
| **霜白** | `#F5F0E8` | 全站主背景（宣纸色） |
| **月白** | `#E8EEF2` | 卡片背景 |
| **墨黑** | `#1A1A1A` | 正文主文字 |
| **青瓷** | `#7BA3A8` | 次要文字、边框 |

配色比例：霜白/月白纸色系背景约 60%，绛赤/玄青等强调色约 30%，缃黄/翠青点缀约 10%。
模块色彩标识：哲学=玄青+缃黄、古籍=霜白+绛赤、儒道=缃黄+翠青、书法=墨黑+月白+青瓷、诗歌=翠青+霜白、近现代史=绛赤+墨黑、长征=缃黄+绛赤、科学=翠青+月白+青瓷。

### 2.2 纹样规范（SVG 矢量实现）

```
全局装饰纹（按场景选用）：
- 首页大图区：云纹 + 山水
- 内容模块标题栏：回纹边框
- 卡片内容区：细线分割（借鉴简牍样式）
- 页脚：祥云纹 + 水波纹分隔
- 背景：淡淡的水墨山水纹理 / 冰裂纹（低透明度 4%-8%）
- 栏目标签：方胜纹 / 如意纹
- 按钮四角：回纹微装饰
```

实现方式：SVG 内联或独立 .svg 文件，CSS background/mask 引用；保证文字可读性。

### 2.3 Logo 设计方向

```
方案：以"知常轩"三字为核心
- 主字体：篆书或隶书（体现厚重文化感）
- 辅助：一方红色印章（阳刻"知常"）
- 可选英文：Zhichangxuan Academy
```

### 模块一：中国哲学

**定位**："哲学是全部科学之母"——帮助青少年建立思维框架，理解世界本质
**色彩主调**：玄青 + 缃黄

**内容结构**
1. **先秦诸子（入门篇）**
   - 诸子群像：儒道法墨名阴阳，12 位先秦思想家生平与核心主张（图文 + 趣味问答）
   - 思想地图：诸子百家师承关系、争论焦点可视化图（交互图表）
   - 漫画诸子：每位思想家 3~5 幅漫画故事（漫画连载）
2. **中国哲学核心概念（词典式）**：道、气、阴阳、五行、天人合一、中庸——哲学含义 + 生活联系
3. **思维方法专题**：矛盾分析法、知行合一与学习习惯、盲人摸象与全面看问题、概率思维
4. **青少年哲学对话**："我是谁"、自由意志存在吗、什么是真正的勇敢、中国哲学里的幸福密码

**首批内容（A 级优先）**
- 道德经选章精讲（道法自然、上善若水、知常曰明）——网盘《道德经全文及译文.pdf》作底本（A）
- 论语选章（学而、为政）——网盘《论语》目录（A）
- 荀子选篇——网盘《荀子》目录（A）
- 庄子的三条鱼（故事化）——自撰（A）
- 增广贤文选段——网盘《增广贤文全文及解释.pdf》（A）

### 模块二：经典古籍

**定位**：不求背诵，只求理解——让孩子读懂古人的智慧，而不是埋在故纸堆里
**色彩主调**：霜白 + 绛赤

**内容结构**
1. **必读经典导读（分级）**
   - 启蒙级（小学）：三字经、百家姓、千字文、声律启蒙——动画微课 + 朗读音频
   - 进阶级（初中）：论语、孟子、老子、庄子精选——讲解 + 思维导图
   - 深度级（高中）：史记选篇、礼记、周易基础——原典精读 + 批注
2. **古籍精读课**（每部经典）：作者与成书背景 → 核心篇章逐句讲解（图文+音频）→ 典故与现代联系 → 思考题 → 成语汇总
3. **经典人物**：孔子、司马迁、苏轼、王阳明
4. **古文学习工具**：古汉语字典（在线）、文言虚词用法表、通假字汇总、古文今译对照库

**首批内容（A 级优先）**
- 史记·项羽本纪选读（破釜沉舟）——网盘《中华书局简体本二十四史》（A，原文公有领域）
- 二十四史今译对照 3 篇——网盘《二十四史全译》（A/B）
- 资治通鉴选读——网盘《资治通鉴合集》（A）
- 三字经注音朗读 10 讲——自整理（A）
- 古文观止选篇——网盘《创世卓越-古文观止.pdf》（A/B）

### 模块三：儒与道

**定位**：理解儒家积极入世与道家超然物外两种人生智慧——儒道互补，才是完整的中国精神
**色彩主调**：缃黄 + 翠青

**内容结构**
1. **儒家思想体系**：儒学发展脉络（孔子→孟子→荀子→董仲舒→朱熹→王阳明）；核心价值观仁/义/礼/智/信；《论语》名句精讲 50 句（原文+今译+现实应用+讨论题）；儒家与现代教育（因材施教、学而时习之、有教无类）
2. **道家思想体系**：发展脉络（老子→庄子→黄老道家→魏晋玄学）；道德经 81 章逐章解读；庄子故事（庄周梦蝶、庖丁解牛、井蛙语海、材与不材）；道家与现代生活（无为而治不是躺平、上善若水、道法自然）
3. **儒道对比专题**：人生价值、面对困境、人际关系、学习态度、教育方式对比表
4. **家长课堂**：如何跟孩子讲儒道

**首批内容（A 级优先）**
- 道德经第 1/16 章精讲（道可道、致虚极）
- 论语名句 10 句精讲
- 孔子 vs 老子（如果两位老师相遇）
- 家长课堂：孩子问"为什么要善良"怎么答

### 模块四：书法文化

**定位**：书法是中华文化的基因工程——让孩子不仅会写字，更能欣赏书法之美
**色彩主调**：墨黑 + 月白 + 青瓷

**内容结构**
1. **书法简史（时间线互动）**：甲骨文→金文→大篆→小篆→隶书→楷书→行书→草书（配代表作品图）
2. **五体书详解**：篆（李斯·峄山碑）、隶（蔡邕·乙瑛碑，首选入门）、楷（颜柳欧赵·玄秘塔/九成宫，最佳入门）、行（王羲之·兰亭序）、草（张旭/怀素，后期）
3. **名家名帖赏析**：兰亭序、祭侄文稿、黄州寒食帖、松风阁诗帖、洛神赋
4. **书法入门教程**：认识工具（笔/墨/纸/砚）→ 笔画基础（永字八法）→ 结构原则 → 碑帖临摹
5. **趣味书法**：汉字演变动画、书法家故事（漫画）、异体字、匾额文化

**首批内容（A 级优先）**
- 碑帖欣赏专栏 5 篇——网盘《060 书法研究/100 碑帖》（历代碑帖影印公有领域，A）
- 历代书法全集高清图库选展（标注作者年代，A）
- 永字八法图文教程（自撰，A）
- 打印描红字帖（一年级 20 张，自产）
- 注：书法资料主体在 I_am_Jerry2020 网盘（2748G），如需更全碑帖从该网盘获取

### 模块五：诗歌国度

**定位**：诗不是用来背的，是用来感受的——让孩子真正体会诗词之美，而不只是应付考试
**色彩主调**：翠青 + 霜白

**内容结构**
1. **诗词发展史**：诗经→楚辞→汉赋→乐府→唐诗→宋词→元曲→近现代诗（时间轴）
2. **诗词分类阅读**：
   - 山水田园诗派：王维、孟浩然、陶渊明（意象分析法）
   - 边塞军旅诗派：高适、岑参、王昌龄（关联学习：地图上的边塞诗）
   - 咏史怀古诗：杜甫、刘禹锡、苏轼（知人论世）
   - 送别诗与友情：王勃、李白、王维
3. **诗词创作入门**：押韵平仄、意象词典（100 核心意象）、绝句四步法、对联基础
4. **诗词与科学（创新栏目）**："月落乌啼霜满天"月亮运行规律、"春风不度玉门关"季风、"春江水暖鸭先知"比热容
5. **诗词闯关（互动游戏）**：诗句接龙、看图猜诗、飞花令、诗人身份测试
6. **诗词地图**：诗人行迹/诗作地点接入地图（复用 Leaflet 技术）

**首批内容（A 级优先）**
- 小学生必背古诗 75+70 首精讲（前 10 首）——网盘《003 诗词古文》（古诗原文公有领域 A；配套音频 B 仅参考）
- 山水田园/边塞/咏史/送别四派各 3 首精讲（A）
- 古诗海选篇（A/B）
- 飞花令·月 在线对战（功能开发）

### 模块六：近现代史

**定位**：以史为鉴，可以知兴替——不是灌输仇恨，而是培养历史理性与民族自信
**色彩主调**：绛赤 + 墨黑

**内容结构**
1. **近代中国时间轴（1840-1949）**：鸦片战争→南京条约→太平天国→火烧圆明园→甲午战争→戊戌变法→八国联军→辛亥革命→五四运动→中共成立→九一八→卢沟桥→抗战胜利→新中国成立（大事记卡片）
2. **重大事件专题**：鸦片战争与不平等条约、甲午战争、辛亥革命、五四运动（每专题含背景、经过、影响、思考题）
3. **重要历史人物**：林则徐、魏源、孙中山、李大钊、毛泽东、周恩来、鲁迅
4. **少年红色故事**：适合中小学生的英烈与奋斗故事
5. **历史图片馆**：历史照片与文物图（标注来源）
6. **复兴之路（数据可视化）**：从一穷二白到世界第二大经济体（钢产量、铁路、教育、航天）
7. **历史纪录片推荐**：大国崛起、觉醒年代、长征、我和我的祖国（仅推荐，不提供片源）

**首批内容**
- 近代大事时间轴 15 个节点图文（A，史实公有领域，表述以教材为基准）
- 虎门销烟、甲午海战、五四运动 3 个专题（A）
- 徐中约《中国近代史》导读 1 篇（C，仅书目）
- 全球通史导读 1 篇（C，仅书目）

### 模块七：长征精神

**定位**：长征是宣言书、宣传队、播种机——理解长征，才能理解中国共产党为什么能
**色彩主调**：缃黄 + 绛赤

**内容结构**
1. **长征全景（地图交互）**：起点瑞金、终点吴起镇/会宁，全程约 25000 里，1934.10-1936.10，四支红军部队——由子应用「我走长征路」承载
2. **长征重要节点**：湘江战役（8.6 万→3 万）、遵义会议（历史转折）、四渡赤水（3 万 vs 40 万）、强渡大渡河/飞夺泸定桥（13 根铁链）、过雪山草地（平均海拔 4000 米+）
3. **长征中的故事**：半截皮带、军需处长、"跟着走"、9 岁小红军、藏族同胞助红军
4. **长征诗词赏析**：七律·长征、清平乐·六盘山、忆秦娥·娄山关、《长征组歌》选段
5. **长征精神的现代意义**：理想信念、艰苦奋斗、团队协作；"如何走好自己的长征路"
6. **长征数字**：25000 里、18 座大山、24 条河流、14 个省（数据可视化）
7. **长征纪录片推荐**：《长征》(2016, 8 集)、《我的长征》(2006)

**首批内容**
- 子应用：我走长征路（已上线，持续迭代）
- 长征故事 8 篇（A，史实公有领域）
- 长征诗词 3 首精讲（A）
- 长征文物故事 5 篇：草鞋、扁担、半条被子、七根火柴（A）
- 注：网盘无独立长征专题目录，长征内容以现有应用 + 权威史料整理为主

### 模块八：当代科学

**定位**：科技强国——让孩子理解当代科学前沿，激发探索欲，培养科学精神
**色彩主调**：翠青 + 月白 + 青瓷

**内容结构**
1. **物理世界**：经典力学（牛顿三定律、能量守恒）、电磁学（闪电、电磁铁、电动机）、量子物理入门（双缝实验、量子纠缠、量子通信中国领先）
2. **化学世界**：元素周期表探秘（元素起源、稀土、黄金）、化学反应与生活（燃烧、生锈、厨房火山、电池）、有趣化学实验（彩虹瓶、水中花园、隐形墨水）
3. **生物世界**：进化论入门（达尔文、自然选择）、基因与 DNA（双螺旋、转基因、CRISPR）、生态系统（食物链、碳循环、物种灭绝）
4. **天文与宇宙**：太阳系探秘、宇宙学入门（大爆炸、黑洞、暗物质）、中国航天成就（神舟、天宫、嫦娥、天问、长征火箭）
5. **数学思维**：数学中的美（斐波那契、黄金分割、欧拉公式）、数学与生活（概率思维、统计陷阱、复利）、数学史关键时刻（零、负数、无理数）
6. **前沿科技专题**：人工智能（神经网络、ChatGPT、AI 伦理）、新能源（太阳能、核聚变、氢能、中国新能源成就）、生物技术（疫苗、克隆、3D 生物打印）
7. **家庭小实验**：材料清单+步骤+原理+安全提示（每篇含安全声明）
8. **科学辟谣**：谣言粉碎机系列

| 层级 | 采用方案 | 理由 |
|------|----------|------|
| 后端 | Python Flask（现有） | 与我走长征路同栈，认证/媒体/审核/投稿系统全部可复用 |

| 前端 | Jinja2 模板 + 原生 JS/CSS | 首期零构建成本；交互组件（测验/飞花令）渐进引入 Vue3 |
| 地图 | Leaflet（现有） | 我走长征路已用，诗词地图直接复用 |
| 部署 | 现有 dev/prd 双环境（Nginx + gunicorn） | 沿用版本管理方案 V3.1 流程 |
| 域名 | zhichangxuan.com 主站 + cz.zhichangxuan.com 子应用 | 已备案，公安备案已通过 |

### 6.2 新增数据模型

- module 表：模块（编号、名称、图标、简介、排序、状态）
- article 表：文章（标题、模块、栏目、正文、原文/注释/译文三段式、封面、标签、适龄分级、状态、发布时间、浏览量）
- daily_saying 表：每日一句（原文、出处、今译、场景、日期）

### 6.3 页面结构

- 首页：banner（云纹+山水）→ 每日一句 → 8 模块网格 → 今日推荐 → 资源中心入口 → 家长学堂入口 → 页脚（备案信息）

## 七、资源访问架构（新增章节：百度网盘与网站结合）

### 7.1 核心原则

**内容进站，文件留网盘。** 真正要"进网站"的是加工后的内容（文本+压缩图，服务器绰绰有余）；原始大文件（高清碑帖、整套 PDF、视频课程）不下载到服务器，通过网盘通道提供给访客。

### 7.2 三层架构

| 层 | 内容 | 存储 | 处理 |
|----|------|------|------|
| 内容层 | 文章、诗词、故事、每日一句（纯文本） | 服务器 SQLite | 加工后进库，体积可忽略（1 亿字约 200MB） |
| 图片层 | 配图、碑帖缩略图、书法欣赏图 | 服务器静态目录 | 压缩为 WebP/分级缩略图（几百 KB/张）；原图留网盘 |
| 资源层 | 完整 PDF、高清碑帖原图、视频课程 | 百度网盘 | 网站只存元数据 + 分享链接，点「前往网盘获取」 |

### 7.3 资源中心实现（方案 A：分享链接导航——首期采用）

1. **元数据入库**：网盘目录树/文件名/大小/简介存入 resource_link 表（只存文本，几百 KB 级）
2. **分享链接生成**：对确定开放的资源，用已登录的托管浏览器调用百度网盘分享接口（share/set）批量生成分享链接+提取码，存入数据库；**分批操作（每批 10-20 个，间隔执行），规避百度风控**
3. **网站展示**：资源中心页渲染目录树 + 书目卡片（书名/作者/分级/简介）+「前往网盘获取」按钮（新窗口打开分享页）
4. **链接巡检**：定期（如每月）脚本检查链接有效性，失效标记下架
5. **优点**：服务器零存储压力、实现简单、无版权暴露风险（C 级书目本就只给导航）
6. **缺点**：跳转网盘需登录/提取码，体验割裂——公益资料站主流做法，可接受

### 7.4 预留演进（方案 B：开放平台 API 直链——二期评估）

- 申请百度网盘开放平台应用，用户 OAuth 授权后，后端调 /api/download 换文件直链（dlink），302 跳转或服务器代理
- 优点：站内一体化浏览下载；缺点：个人应用审核门槛、非会员下载限速（约 100KB/s）、token 放服务器有账号安全风险、风控封号可能
- 结论：体验优化项，不作为首期依赖

### 7.5 预留演进（方案 C：低频对象存储兜底——按需启用）

- 个别必须站内直出的资源（如高清碑帖原图精选）：阿里云 OSS 低频访问（约 0.08-0.12 元/GB/月）或归档存储，配合 CDN（七牛/又拍云免费额度）
- 比网盘 API 稳定，比标准存储便宜一个数量级；能不进就不进

### 7.6 与内容生产的结合

- A 级资源（古籍原文/碑帖影印）→ 下载后加工成网站内容（提取→校对→三段式排版→注音→TTS→审核→发布），原文公有领域可放心用
- B 级资源 → 作加工底本/参考，不直接上线
- C 级资源 → 全部进「延伸阅读」书目导航库（书名/作者/出版社/导读），不提供文件
- 首批试点：《道德经》《论语》《增广贤文》+《史记》选篇（A 级，跑通「下载→加工→上线」流水线）

## 八、内容生产与合规

### 8.1 内容来源与版权（红线）

- 古籍原文、历史事实：公有领域，标注出处（如《论语》《史记》）
- 白话解读、故事改编：自撰原创，标注作者
- 图片：优先自绘/原创 SVG；历史照片标注来源与授权状态；碑帖用公有领域高清资源
- 音频：TTS 合成 + 志愿者配音并行
- 现代出版物（中信国学大典、徐中约、柏杨、DK、教辅等）：一律不上传内容，仅书目导航
- 转载原则：不转载未授权内容；引用注明出处

### 8.2 未成年人保护合规（《未成年人保护法》网络保护专章）

1. 不收集儿童个人信息：浏览无需注册；投稿/留言仅需昵称（可匿名）
2. 家长模式：家长可设置「共读模式」，仅查看站内学习行为数据，不外传
3. 内容适龄分级：每篇标注适龄建议（6-9 / 10-12 / 13-15），战争等题材弱化血腥描写
4. 审核机制：投稿与留言先审后发（沿用现有 spark 审核流程）
5. 举报通道：页面提供举报入口，明确处理时限
6. 防沉迷：无自动播放流、无信息流无限刷
7. 无广告、无付费、无外链商业推广

### 8.3 内容更新节奏（上线后）

| 内容类型 | 更新频率 |
|----------|----------|
| 每日一句 | 每日 |
| 核心文章 | 每周 2~3 篇 |
| 音频朗读 | 每周 1 首诗词/古文 |
| 专题策划 | 每月 1 个大专题（如"长征月""科学月"） |
| 互动活动 | 每季度 1 次 |

```
短期（1年）：纯公益
- 内容完全免费；资金来源：创始人/社会捐助；欢迎志愿者（教师、大学生、书法/美术爱好者）参与创作与审核（给署名）
中期（2~3年）：部分自造血
- 图书/文创销售收入、机构/学校定制内容、基金会赞助
长期（3年以上）：公益可持续
- 申请公募基金资格、面向公众募款、保持内容免费公益
```
