重走长征路 — 长征文化数字地图

项目简介

交互式长征历史数字展示平台。以"重走长征路"为核心交互形式，全方位展示中国工农红军长征这一重大历史事件的全貌。融合 WebGIS 地图技术与交互式节点系统，打造"看得见、点得到、听得着"的沉浸式长征文化学习工具。

版本

V1.0.0（详见 VERSION、CHANGELOG.md）

技术栈

层 技术
前端 Leaflet.js + OpenStreetMap
后端 Python Flask
数据库 SQLite（开发）/ PostgreSQL + PostGIS（生产）
文档 Doxygen

项目结构

  • 001 项目源码/ — Flask 全栈 Web 应用
    • api/ — REST API 路由（5 个蓝图：auth、node、media、route、spark）
    • services/ — 业务逻辑层（6 个管理器）
    • models/ — 数据模型（Node、User、Media、Spark）
    • static/ — 前端资源（CSS、JS、图片）
    • templates/ — HTML 模板
    • data/ — SQLite 数据库 + node_data.json
  • 002 项目资源/ — 节点照片资源
  • 004 项目文档/ — 项目文档（含 Doxygen 生成文档）
  • 008 设计备份/ — 设计方案历史版本

长征节点

29 个节点，按时间线组织（瑞金→湘江→遵义→赤水→金沙江→大渡河→雪山草地→会宁）。

详见 节点信息V1.0.0.docx。

启动

cd "001 项目源码"
python run.py

默认访问 http://127.0.0.1:5000

管理员账号：admin / admin123

设计理念

  • **路线即叙事**：以长征实际地理路线为主线，节点为叙事锚点，用户以"走"的方式体验历史进程
  • **交互即学习**：通过节点激活、内容展开、语音播报等交互方式，让用户在操作中获取知识
  • **开放即共建**：设计用户可上传内容、可动态创建节点的体系，支持社区化运营
  • **开源即传承**：项目源代码完全开源，欢迎社区贡献，让长征精神以技术方式永久传承
