API 更新

GET /api/v1/nodes 新增查询参数：

  • army — 按军队过滤，可选值：
    • 中央红军 — 红一方面军
    • 红二方面军 — 贺龙、任弼时部
    • 红四方面军 — 张国焘、徐向前部
    • 红25军 — 程子华、吴焕先、徐海东部

排序规则: 军队顺序（中央红军→红25军→红二方面军→红四方面军），同军按时间升序

注意事项

  1. 现有的 1 个旧有额外节点未被修改，标志为 army='中央红军'
  2. 新节点的数据基于真实历史，每节点包含完整的 8 项内容（famous_battle, important_meeting, history_event, core_site, poem_article, typical_story, typical_people, historical_significance）
  3. 节点 ID 命名规范：中央红军数字编号（1.1-14.2），红二方面军 E 前缀，红四方面军 S 前缀，红25军 H 前缀
  4. 部分中央红军节点的某些内容字段为 null 属于正常情况（该节点无对应历史事件）
