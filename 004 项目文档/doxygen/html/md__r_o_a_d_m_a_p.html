开发路线图

V1.1.0 — 内容增强（优先级：高）

  • 节点照片：信息面板顶部显示高清照片（002 项目资源/ 加载，没有的以军旗替代）
  • 补充节点数据：完善长汀、通道、黎平等节点的诗词文章、典型故事等空白字段
  • 补充图片资源：按《照片获取指南》批量下载各节点百度百科/纪念馆图片

V1.2.0 — 交互增强（优先级：中）

  • 漫游控制：速度选择（低速/中速/高速）、暂停/继续/跳过/重头
  • 留言板后端 API：CRUD + 管理员管理
  • 节点搜索：按关键字搜索节点并定位到地图

V2.0.0 — 多军路线（优先级：中）

  • 红二方面军路线 + 节点数据（route_point 补充）
  • 红四方面军路线 + 节点数据
  • 红二十五军路线 + 节点数据
  • 多路线叠加显示 / 独立切换

V2.1.0 — 用户共建（优先级：低）

  • 用户创建节点：前端表单 → 审核 → 入库 → 重画路线
  • 星火投稿前端完善：富文本编辑器、文件上传进度
  • 用户个人中心：我的投稿、我的留言

V3.0.0 — 生产就绪（优先级：低）

  • PostgreSQL + PostGIS 迁移
  • Gunicorn + Nginx 生产部署
  • Docker 一键部署
  • 性能优化 + CDN 加速
  • 移动端响应式适配全面优化

版本命名规则: V主版本.次版本.修订号

  • 主版本：重大架构/功能变更
  • 次版本：功能新增
  • 修订号：Bug 修复 / 小优化
