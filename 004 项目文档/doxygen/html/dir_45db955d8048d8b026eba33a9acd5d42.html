部署流程

首次部署到 Linux 服务器：

# 1. 上传脚本到服务器，首次初始化
./deploy.sh --init
# 2. 设置安全密钥后部署
SECRET_KEY=your-secure-key-here ./deploy.sh

日常更新（服务器上）：

cd /opt/longmarch-map
./006\ build/deploy.sh

手动启动

cd 001 项目源码
gunicorn -c ../006\ build/gunicorn_config.py wsgi:app
