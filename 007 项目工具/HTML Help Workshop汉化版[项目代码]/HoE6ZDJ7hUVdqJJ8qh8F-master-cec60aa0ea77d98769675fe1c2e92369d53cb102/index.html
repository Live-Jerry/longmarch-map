工具概述

工具简介

Microsoft HTML Help Workshop 是一款专业的工具，用于创建、编辑和编译HTML格式的帮助文件。汉化版将英文界面和帮助文档翻译成中文，极大方便了中文用户的使用体验。

核心组件

  • HTML编辑器
  • 索引工具
  • 目录编辑器
  • 编译器
  • 资源管理

核心功能特性

HTML编辑器

  • 文本编辑和格式化
  • 插入图片和链接
  • 创建表格和列表
  • 代码提示和自动完成

索引工具

  • 关键词和主题提取
  • 索引结构组织优化
  • 关键词搜索和模糊匹配
  • 搜索结果展示导航

目录编辑器

  • 章节和子章节管理

HTML编辑器

主要功能

文本编辑和格式化

支持文本输入编辑、字体样式设置、段落格式化、列表和缩进等基本功能

插入图片和链接

支持从本地文件或网络URL插入图片，创建超链接并设置链接属性

创建表格和列表

支持创建带有行列的表格，设置表格属性，创建有序和无序列表

使用技巧

代码提示和自动完成

提供HTML标签和属性的代码提示，自动完成代码输入，提高编码效率

预览功能和实时编辑

支持实时预览文档渲染效果，修改代码时预览窗口实时更新

HTML代码优化和验证

自动优化HTML代码，验证语法和语义，报告错误和警告

索引工具

索引创建和管理

关键词和主题提取

支持自动扫描帮助文件提取关键词，也支持手动添加重要概念

索引结构组织优化

采用树形结构按层次组织关键词，考虑同义词和交叉引用

索引搜索和使用

关键词搜索和模糊匹配

支持关键词或短语搜索，即使输入不完全准确也能找到相关结果

搜索结果展示和导航

以列表形式显示搜索结果，支持布尔运算符和近似搜索选项

编译器

编译过程

HTML文件整合

将所有HTML文件合并到主HTML文件中，包含所有帮助主题内容

索引和目录集成

集成索引信息支持关键字搜索，添加目录结构提供内容导航

帮助文件格式生成

生成CHM格式帮助文件，可由Windows帮助查看器打开查看

编译选项和设置

输出格式和压缩方式

支持CHM、HTML、RTF、PDF等格式，提供LZX、CAB等压缩方式

安全和版权声明

支持密码保护、数字签名、内容加密等安全设置，可添加版权信息

代码示例

hhc -b -cr -t chm -o output.chm input.hhp

构建帮助文件、创建目录、指定CHM格式输出

  • 翻译准确性和一致性

  • 稳定性和兼容性
